# 📊 Customer Segmentation (RFM Analysis) using PostgreSQL & Power BI

## 📌 Project Overview

This project performs **Customer Segmentation** using the **RFM (Recency, Frequency, Monetary)** methodology on an online retail dataset. The goal is to identify valuable customer groups, analyze purchasing behavior, and generate actionable business insights using **PostgreSQL** and **Power BI**.

The project follows an end-to-end analytics workflow, including data exploration, cleaning, RFM metric calculation, customer segmentation, business analysis, and interactive dashboard creation.

---

## 🎯 Business Problem

Businesses often struggle to identify their most valuable customers and understand purchasing patterns.

This project helps answer questions such as:

* Who are the most valuable customers?
* Which customers are at risk of churning?
* Which customer segments generate the highest revenue?
* How does revenue change over time?
* Which products and countries contribute the most sales?

## 🧹 Data Cleaning

The following cleaning steps were performed:

* Removed records with missing Customer IDs
* Removed cancelled transactions
* Removed records with invalid quantities
* Removed records with invalid prices
* Converted invoice dates into PostgreSQL timestamp format
* Calculated transaction revenue

---

## 📊 RFM Analysis

Each customer was evaluated using three key metrics:

### Recency (R)

Days since the customer's most recent purchase.

### Frequency (F)

Number of unique orders placed by the customer.

### Monetary (M)

Total revenue generated by the customer.

Customers were scored using PostgreSQL's `NTILE()` window function.
